# Imágenes de la flota

Sube aquí las fotos de las aeronaves. Cada ficha de `js/data/aircraft.js` enlaza a su imagen con el campo `image` (por ejemplo `"image": "img/nh90.jpg"`).

Para que una foto aparezca, el nombre del archivo debe ser **exactamente** el de esta tabla: en minúsculas y con extensión `.jpg`. Si una imagen falta, la web muestra un recuadro con el nombre de la aeronave.

| Archivo | Aeronave |
|---|---|
| `eurofighter.jpg` | Eurofighter Typhoon (C.16) |
| `ef18.jpg` | EF-18M Hornet (C.15) |
| `f5m.jpg` | Northrop F-5M (AE.9) |
| `a330mrtt.jpg` | Airbus A330 MRTT (TK.24) |
| `a400m.jpg` | Airbus A400M Atlas (T.23) |
| `c295.jpg` | Airbus C295M (T.21) |
| `cn235.jpg` | CASA CN235 (T.19B) |
| `cn235vigma.jpg` | CASA CN235 VIGMA (D.4) |
| `c295msa.jpg` | Airbus C295 MSA/SAR (D.6) |
| `c295mpa.jpg` | Airbus C295 MPA |
| `pc21.jpg` | Pilatus PC-21 (E.27) |
| `hurjet.jpg` | TAI Hürjet |
| `mq9.jpg` | General Atomics MQ-9A Reaper Block 5 |
| `nh90.jpg` | NH90 «Lobo» (HD.29) |
| `superpuma.jpg` | Aérospatiale AS332 Super Puma (HD.21) |
| `s76.jpg` | Sikorsky S-76C (HE.24 / HD.24) |
| `h175m.jpg` | Airbus H175M |

## Recomendaciones

- Usa fotos horizontales de unos 1200 × 800 px y menos de 300 KB, para que la página cargue rápido.
- Si una foto es `.png` o `.webp`, cambia también la extensión en el campo `image` de su ficha.
- Usa fotos con licencia libre (por ejemplo, Wikimedia Commons o las de Defensa) y anota aquí su autor.
