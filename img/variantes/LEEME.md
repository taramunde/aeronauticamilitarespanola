# Fotos de variantes

Cada variante busca su foto aquí. Si falta el archivo, la variante se muestra sin foto.
Formato recomendado: .webp horizontal (16:9), unos 1280 × 720 px.
Pon el autor y la licencia en `imageCredit` dentro de `js/data/aircraft.js`.
